# Proyecto clase05-jsintro

## Descripción

Formulario web para registrar productos utilizando HTML y CSS nativo.

## Características

- Documento HTML con idioma español.
- Diseño responsive para dispositivos móviles.
- Formulario centrado en pantalla.
- Campos obligatorios para:
  - Nombre del producto.
  - Precio.
  - Stock disponible.
- Validación HTML mediante `required`, `min` y `step`.
- Botón para guardar el producto.
- Estilos visuales sin frameworks externos.
- Estados `hover`, `focus` y `active` en los controles.
- Diseño basado en colores neutros, bordes redondeados y sombras.

## Archivos principales

- `index.html`: estructura y formulario de registro.
- `index.css`: estilos visuales y diseño responsive.

## Cambios realizados

- Se creó la estructura HTML del formulario de registro de productos.
- Se agregaron campos para nombre, precio y stock.
- Se incorporaron validaciones básicas mediante atributos HTML.
- Se vinculó `index.html` con `index.css`.
- Se implementaron estilos nativos para:
  - Formulario.
  - Etiquetas.
  - Inputs.
  - Botón de envío.
  - Estados de interacción.
  - Adaptación para pantallas pequeñas.
- Se agregó una apariencia visual limpia y moderna mediante CSS nativo.

## Ejecución

Abrir `index.html` directamente en un navegador web.

No requiere instalación de dependencias ni servidor adicional.
